# Apuntes pedagógicos

Esta carpeta contiene apuntes importados que sirven como **contexto pedagógico** para diseñar lecciones.

- No son contenido final tal cual — deben adaptarse al formato interactivo de Eaxy.
- Organiza los apuntes por tema (fracciones, proporciones, álgebra, etc.) según vayas importando material.

- Proporciones y regla de tres
