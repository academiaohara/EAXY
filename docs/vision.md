# Visión de Eaxy

Eaxy es una plataforma de aprendizaje interactivo inspirada en Brilliant.org. El objetivo es que los estudiantes aprendan **haciendo**, no memorizando.

## Principios pedagógicos

1. **Aprender haciendo** — Cada lección combina explicación breve con interacción inmediata.
2. **Feedback inmediato** — El alumno sabe al instante si acertó y recibe una explicación.
3. **Pistas progresivas** — Si falla, puede pedir pistas sin revelar la respuesta de golpe.
4. **Visualización** — Manipulativos (barras de fracciones, sliders, selección visual) para construir intuición.
5. **Pasos cortos** — Lecciones de 5–10 minutos con 5–8 pasos cada una.

## Alcance actual (MVP)

- **Materia:** Matemáticas
- **Público:** ESO / bachillerato inicial
- **Idioma:** Español
- **Sin login** — Progreso local en el navegador
